# D19 re-rating (2026-09-23)

**Rule applied** (schema `status`; researcher.md): rate the *core* anomalous claim, the proposition that contradicted the accepted view of its time. Details refined later (dates, layers, interpretations) go in `refinements`; `partial` only when a substantive part of the core claim itself failed; `unsupported` when the evidence was withdrawn or shown insufficient without a positive disproof; `refuted` only for a positive disproof. Separate claims bundled into a record go to `catalog/candidates.json`. Applied to all 26 records from their own contents and sources; no new web research.

## Judgment calls to check

- **Göbekli Tepe** `year_resolved` = 2000 (Schmidt's first dated, peer-reviewed report). No acceptance event is sourced; 2012 (Dietrich et al., no domesticates in Layer III) is the alternative.
- **H. floresiensis**: the ~18 ka survival age, redated to ~100-60 ka, is treated as a date refinement because `orthodoxy_at_claim` concerns the species, not its survival. Counting survival as a failed component would keep it `partial`.
- **Topper** stays `open` but is borderline `unsupported`: the ≥50,300 14C BP dates are minimum ages and no journal report of them was found.
- **Calico Hills** stays `refuted` on two edge-angle tests and the unheated 'hearth'. The record itself notes this is not proof for each piece, so `unsupported` was weighed.
- **Kensington** stays `refuted` on linguistic and runic evidence, which Williams (2012) calls strong but incomplete.
- **Monte Verde** stays `vindicated` despite the 2026 mid-Holocene challenge. The record's existing sensitivity note (re-run analyses with it coded `open`) still applies.
- For Gunung Padang, Jebel Irhoud and Meadowcroft, `what_settled_it` is now null and `settled_by` is `not-settled`, matching the other unresolved records.
- The existing candidate `malakunanja-ii-1990` still gives `expected_status: partial`, written under the old rule. It was left as-is because candidates are append-only; re-check it when it is drafted.
